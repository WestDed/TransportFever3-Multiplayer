# Возможности и границы готовности

Срез и исходники: [ARCHITECTURE.md](ARCHITECTURE.md). «Есть в коде» не означает «проверено в Transport Fever 3». Ни одна игровая функция не принята как стабильная в этом аудите.

| Требование | Статус исходников MPFever 0.3.6 | Основание / оставшаяся проверка |
|---|---|---|
| ПК игрока как хост | Реализовано | `Relay.Start`, запуск игры; проверить интернет/NAT и нагрузку |
| Отдельные компании и возврат | Частично | `CO.join/match`, состояние в сохранении; имя без sid может вернуть чужую запись; сетевой Steam ID не подтверждён |
| Начальный капитал, баланс | Есть в коде | `makeGameAddPlayerCmd`, журнал; проверить списания и штатный доход |
| Отдельные кредиты | Есть в коде, частично | `coLoanEvent`, `coLoansUpdate`; fallback игнорирует кредиты при недоступных модулях; баланс-коррекция не чинит долг |
| Собственные транспорт, линии, дороги/станции/депо | Есть в коде, нестабильно | `PLAYER_OWNED`, actor context, native OwnerFix; известны ошибки повторения стройки |
| Права на чужие объекты | Частично | Запрет закрытых станций и проверка владельца сборов; нет полной серверной проверки всех действий |
| Независимый уровень, опыт, разрешения | Отсутствует полностью независимый режим | `CO.patchProgression` читает прогресс компании хоста; уникальные стройки отдельно фильтруются |
| Контракты | Частично | `mpfOwner`, фильтр линий/уведомлений; нужен тест двух одновременных заявок и смешанных перевозок |
| Общие города, заводы, пассажиры, грузы | Есть штатная симуляция на каждом ПК | Нет единой серверной симуляции; детерминизм и checksums ограничивают расхождение |
| Конкуренция за пассажиров и груз | Не подтверждена как готовая функция | Нет собственной модели; штатный движок может учитывать несколько владельцев, но правила и доходы надо измерить |
| Плата за чужие станции | Частично | `chargeShares`, 100 по умолчанию; проверять один платёж за реальную остановку и после reload |
| Плата за пути, дороги, депо | Отсутствует общий механизм | Требуются договор доступа, правила изменения/закрытия и учёт |
| Сохранение общей сессии | Есть в коде | Скриптовый реестр сохраняется с миром; нет durable event log и транзакционного манифеста |
| Подключение к идущей игре, reconnect | Частично | Передача мира, retry до 5 минут; проверить недоступный peer и смену процесса |
| Восстановление после desync | Частично, возможна потеря/искажение действий | Полная загрузка мира хоста; open issues #16–19 |
| Gigantomaniac | Не проверено | Нет измерений TF3 этого проекта; полные scans, base64 и самый медленный peer — риски |
| Разные ОС/билды в одной игре | Не заявлять | Windows native layouts; общая сборка/моды обязательны до доказательства обратного |
| Без установленной игры | Реализовано для чистых Lua-компонентов | 16 проверок нового набора; см. TESTING.md |

## Известные проблемы по приоритету

| ID | Приоритет | Доказательство и влияние | Следующее действие |
|---|---|---|---|
| AUD-01 | P0 | `MainForm.OnHostMessage(act)` ретранслирует payload/time/co клиента без полного server validation | Привязка соединения к компании, allowlist, порядок, эпоха и зависимость команд |
| AUD-02 | P0 | `C.deser` исполняет `load("return "..s, ..., {})`; тест возвращает 7 из функции, а не отвергает выражение | Data-only parser с лимитами; пустое окружение не гарантирует отсутствие CPU/memory DoS |
| AUD-03 | P1 | `CO.match` при nil sid использует имя; подтверждено тестом, не сетевой атакой | Не авторизовывать компанию одним именем; определить identity/миграцию старых saves |
| AUD-04 | P1 | `CO.signature` не включает sid; смена привязки аккаунта не меняет подпись, expected failure | Версионированный digest реестра с identity и правами |
| AUD-05 | P0 | Открытые upstream #15–20: снос/сигналы/переигрывание дают crashes, потерю действий, разные деньги | Fixtures, журнал зависимости, блок стройки на reload, точный build context |
| AUD-06 | P1 | Упрощённые подписи owners (счётчики), loans (сумма), onboard (количества) не доказывают полное равенство | Отдельный census для диагностики, сильнее обычные digests; не проверять только деньги |
| AUD-07 | P1 | Исправляется balance, не debt/history; общая progression | Учет по компании, игровая сверка штатных правил |
| AUD-08 | P1 | `ReadLine` без верхнего лимита, синхронные Writer/Broadcast, произвольное n массива частей в OnResyncFile | Ограничения сообщения/очереди/таймаутов и снимка, защита от slow peer |
| AUD-09 | P2 | Старый lockstep падает на отсутствующем module mock; 3 строки не переведены | Исправить fixture после изолированного теста, обновить lang отдельно |
| AUD-10 | P1 для масштабирования | `chargeShares` сканирует линии; полные state scans и сборка base64-копий сохранения | Профилировать; кеш/dirty sets только после проверки идентичности |

Expected failure в новом наборе относится к AUD-02 и AUD-04. Он явно фиксирует требование, которое текущий код не выполняет; дефекты не исправлены в этом PR.

## Открытые сообщения авторскому проекту

Проверены через GitHub 12.10.2026; сообщения пользователей — не результаты нашего запуска. Номер ошибки сам по себе не доказывает, что её причина полностью установлена.

- [#15](https://github.com/dkdknight/MPFever/issues/15): снос уличной станции, removalPlan теряет toRemove, сбой другого игрока. В текущем коде removalPlan действительно строит список сегментов, не отдельный список сооружений.
- [#16](https://github.com/dkdknight/MPFever/issues/16): повтор установки сигнала меняет свойства сегмента/туннель; мир хоста при resync закрепляет неправильную геометрию.
- [#17](https://github.com/dkdknight/MPFever/issues/17): действие между сохранением и загрузкой теряется у отправителя.
- [#18](https://github.com/dkdknight/MPFever/issues/18): удержание стройки ошибочно сбрасывается без загрузки; поздние команды.
- [#19](https://github.com/dkdknight/MPFever/issues/19): быстрые правки модульной станции опережают завершение предыдущей.
- [#20](https://github.com/dkdknight/MPFever/issues/20): разные настройки сноса приводят к разной цене; коррекция денег скрывает причину.
- [#21](https://github.com/dkdknight/MPFever/issues/21): копирование составов вызывает dump/stall всей сессии.
- [#22](https://github.com/dkdknight/MPFever/issues/22): callback назначения на линию получает неполный result.
- [#7](https://github.com/dkdknight/MPFever/issues/7): длительный дрейф городов; [#3](https://github.com/dkdknight/MPFever/issues/3): crash загрузки клиента. Требуют воспроизведения после новых фиксов.
- [#6](https://github.com/dkdknight/MPFever/issues/6): Steam P2P предлагается, не считать реализованным транспортом.

0.3.6 содержит заявленные исправления #12–14 и #4; это не закрывает перечисленные свежие ошибки и не является нашим игровым подтверждением.
